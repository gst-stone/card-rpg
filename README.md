# Card RPG

A small Godot 4 card-battle prototype.

## Current features

- Turn-based combat
- 5-card starter deck
- Draw pile and discard pile
- 3-card hand
- Energy system
- Strike / Fireball / Guard / Heavy Blow
- Enemy scaling damage by turn
- Victory / defeat states
- Restart with `R`

## Controls

- `1` / `2` / `3`: play the card in hand
- `E`: end turn
- `R`: restart battle

Open the project with Godot 4.x and run `scenes/main.tscn`.
